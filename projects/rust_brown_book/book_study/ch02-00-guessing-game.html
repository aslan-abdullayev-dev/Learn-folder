2.0 — Programming a Guessing Game

Summary

  • let is immutable by default; let mut guess = String::new(); is required because read_line needs to write into it.
  • io::stdin().read_line(&mut guess) reads a line of input into that string by mutating it in place (no new String returned) — it returns an io::Result.
  • .expect("message") unwraps a Result: returns the Ok value, or panics with your message on Err.
  • .trim() strips leading/trailing whitespace (including the newline read_line leaves behind); .parse() converts the String to another type and returns a Result.
  • Shadowing lets let guess: u32 = guess.trim().parse()... reuse the name guess for the parsed number, instead of inventing a second variable name for the converted value.
  • let guess: u32 = match guess.trim().parse() {
    Ok(num) => num,
    Err(_) => continue,
};
    This compiles because continue never produces a value — it can stand in for whatever type the Ok arm requires.
  • std::cmp::Ordering (Less / Greater / Equal) plus guess.cmp(&secret_number) drives a second match to compare the guess against the answer.
  • The whole game runs inside loop { ... }, exiting via break once the Ordering::Equal arm is hit.
  • External crate rand: add it under [dependencies] in Cargo.toml, then use rand::Rng; and call rand::thread_rng().gen_range(1..=100) to get the secret number.
  • Dependency versions use SemVer caret requirements by default — rand = "0.8.5" means >=0.8.5, <0.9.0. Cargo.lock then records the exact resolved versions so rebuilds stay reproducible.
