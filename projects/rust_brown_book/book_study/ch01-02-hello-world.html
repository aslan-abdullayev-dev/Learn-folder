1.2 — Hello, World!

Summary

  • Source files use the .rs extension; filenames use snake_case (e.g. hello_world.rs).
  • fn main() { ... } is the required entry point — it always runs first. Opening brace stays on the same line as the declaration.
  • println! is a macro, not a function — the ! is what marks it as one. Statements inside end with ;.
  • Compile with rustc main.rs, then run the resulting binary separately: ./main (Linux/macOS/PowerShell) or .\main (Windows cmd). On Windows this also produces a .pdb file holding debug symbols — not needed to run the program, just to debug it.
  • Rust is ahead-of-time compiled: you must compile before running, unlike Python/Ruby/JS. The upside — the compiled binary runs on a machine with no Rust installed at all.
  • rustfmt auto-formats code (style only, doesn't affect whether it compiles or runs correctly); rust-analyzer powers editor/IDE support. cargo is introduced next for anything beyond a single file.
