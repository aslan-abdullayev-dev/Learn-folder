1.1 — Installation

Summary

  • Install Rust with rustup, the toolchain/version manager — not your OS package manager.
  • rustc --version verifies the install (format: rustc x.y.z (hash yyyy-mm-dd)).
  • macOS/Linux need a linker, usually already present via Xcode Command Line Tools or a C compiler package.
  • rustup update upgrades, rustup self uninstall removes, rustup doc opens the docs offline.
