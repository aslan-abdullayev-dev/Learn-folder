1.3 — Hello, Cargo!

Summary

  • Cargo is Rust's build system and package manager — it ships with the standard Rust install. cargo --version checks it.
  • CommandDoes
    cargo new <name>scaffold a new project
    cargo buildcompile (debug mode by default)
    cargo runbuild and run in one step
    cargo checktype-check only, no executable — fastest feedback
    cargo build --releaseoptimized build
  • Project layout: Cargo.toml (TOML config) + Cargo.lock (exact resolved dependency versions, auto-managed) + src/main.rs (source) + target/ (all build output, never the project root).
  • Cargo.toml has a [package] section (name, version, edition) and a [dependencies] section.
  • Debug build: fast to compile, slower to run. Release build: slower to compile, optimized/fast to run.
  • The same Cargo commands work identically on Linux, macOS, and Windows.
  • To convert an existing non-Cargo project: move the source into src/, then run cargo init.
